# AGENTS.md

## Project Vision

This project is NOT a generic stock application.

The goal is to build a professional “Operating System for Value Investing” combining:

- quantitative analysis;
- qualitative analysis;
- valuation;
- financial intelligence;
- screening;
- AI agents;
- institutional-grade research workflows.

The platform should feel closer to:
- Bloomberg;
- TIKR;
- Koyfin;
- institutional research terminals;
than a retail investing app.

---

# Core Principles

- no generic outputs;
- no shallow analysis;
- no fake financial logic;
- no placeholder financial analysis;
- no overengineered UX clutter;
- prioritize clarity and analytical depth.

---

# Design Philosophy

The UI must feel:
- premium;
- cinematic;
- institutional;
- elegant;
- futuristic;
- minimal;
- interactive.

NOT gamer-like.
