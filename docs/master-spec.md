# MASTER SPECIFICATION
# VALUE INVESTING TERMINAL

---

# PROJECT VISION

The objective is to build an institutional-grade research terminal focused on:

- value investing;
- qualitative analysis;
- quantitative analysis;
- valuation;
- financial intelligence;
- AI-assisted investment research;
- global stock screening.

The platform should feel closer to:
- Bloomberg;
- TIKR;
- Koyfin;
- institutional research terminals;

than a generic retail investing application.

---

# CORE PHILOSOPHY

The platform should combine:

- financial data;
- valuation systems;
- investment frameworks;
- qualitative reasoning;
- quantitative scoring;
- AI agents;
- institutional-grade workflows.

The system should prioritize:
- analytical depth;
- clarity;
- modularity;
- scalability;
- professional UX;
- production-ready architecture.

---

# KNOWLEDGE BASE

The /knowledge directory contains:

- Damodaran valuation books;
- DCF spreadsheets;
- qualitative frameworks;
- investment checklists;
- fund letters;
- sample analyses;
- valuation models;
- research documents.

These files should be used as:

- reasoning systems;
- RAG sources;
- analytical frameworks;
- qualitative guidance;
- valuation references;
- investment heuristics.

The goal is NOT summarization.

The goal is extracting:
- investment logic;
- analytical structures;
- valuation methodologies;
- qualitative reasoning systems.

# ENGINEERING PRINCIPLES

The system should prioritize:

- modular architecture;
- scalability;
- maintainability;
- clean separation of concerns;
- reusable components;
- production readiness;
- strongly typed APIs;
- clean folder structures.

Avoid:
- spaghetti architecture;
- monolithic AI prompts;
- shallow financial logic;
- fake valuation systems;
- placeholder analysis.
