# Valuation Engine

Home for auditable financial calculation modules.

Current scope includes platform-owned normalized metrics calculated from canonical statements. Valuation models such as DCF, WACC, FCFF, FCFE, multiples, and scenario analysis are intentionally not implemented yet.

## Current Metrics

- Margins.
- Year-over-year growth.
- Return on equity.
- Debt to equity.
- Current ratio.
- Per-share fundamentals.
- Invested capital.
- Operating-income based ROIC proxy.

FMP key metrics are not treated as final platform truth.
